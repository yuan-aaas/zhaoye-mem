# plugin_test

项目的过程文件目录。**不是源码，不进版本库。**

放在这里的：

- 临时脚本、一次性排查代码、抓包/回放数据；
- 验证插件、宿主、CLI 时的输入输出、日志、截图；
- 手工复现目录（例如 `.test-tmp/` 下的测试沙箱）；
- 还没想好放哪、但需要留痕的实验产物。

不放这里的：

- 正式源码（`src/`、`test/`、`plugins/`、`presets/`）；
- 需要长期维护的文档（`docs/`）；
- 构建产物（`dist/`）。

约定：

1. 命名带日期或用途，例如 `2026-10-21-delegate-session/`。
2. 任务结束后可以整个目录删掉，不需要评审。
3. 本目录默认被 `.gitignore` 忽略，只有这份 README 和 `.gitignore` 本身入库。
