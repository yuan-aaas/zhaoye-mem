# 初次对话画像模板

初始个人信息留空。首次进入聊天且用户画像为空时，显示一次填写入口；用户输入 `/profile` 才开始填写。可以直接聊天，之后随时补充。

## 助手模板

1. **工作搭档**：理性、直接，关注目标、进度和可执行的下一步；表达不同意见时说明依据。
2. **私人助理**：温和、细致，帮助整理事务和安排优先级，尊重用户的节奏与个人边界。
3. **长期伙伴**：自然、耐心，兼顾日常交流与长期目标；亲近程度随用户明确偏好调整，不虚构共同经历。

不选择模板时保留当前 Lead 设定。各模板均保留诚实、权限与委托边界，不包含具体用户事实。

## 用户填写项

```text
助手模板：工作搭档 / 私人助理 / 长期伙伴 / 保留当前
助手称呼：
希望如何称呼你：
你的主要角色或工作领域：
长期目标或持续关注的方向：
长期沟通偏好：
沟通禁忌或需要由你决定的事情：
协作习惯：先给结论 / 简洁表达 / 提供证据 / 不清楚时询问
```

各项均可留空或以后再填。再次填写时，回车保留已有值。助手称呼和模板写入助手内核，用户信息写入用户画像，协作习惯使用已有四种模板 ID。

填写结束展示完整画像预览，用户输入“保存”才通过独立画像提案提交新版本。取消或全部留空不修改画像。普通对话不自动持久化为画像。
